**Yeter App**, kullanıcıların güvende kalmalarını sağlamak amacıyla geliştirilmiş gerçek zamanlı bir güvenlik ve harita uygulamasıdır. Kullanıcıların riskli bölgelerden uzak durmalarını sağlayan, tehlike anında hızlıca ihbar oluşturmalarına imkan tanıyan ve dinamik rotalar çizen kapsamlı bir ekosistemdir.

## 🌟 Özellikler

### 📱 Mobil Uygulama (React Native & Expo)
- **Gerçek Zamanlı Harita:** Google Maps API kısıtlamalarına takılmadan, tamamen açık kaynaklı Leaflet (OpenStreetMap) WebView entegrasyonu.
- **Risk Bölgesi Uyarıları:** Tehlikeli (Kırmızı) ve Riskli (Turuncu) bölgelere yaklaşıldığında otomatik "Yüksek Risk" uyarıları.
- **Acil İhbar Sistemi:** Sözlü taciz, fiziksel tehdit, kavga veya şüpheli durumları saniyeler içinde haritaya ekleme.
- **Güvenli Rota Oluşturucu:** Hedefinize giderken riskli sokakları bypass eden, aydınlık ana caddeleri tercih eden güvenli rotalar sunar.
- **Dinamik Navigasyon:** Uygulamanın alt menüleri Admin paneli üzerinden anlık olarak açılıp kapatılabilir ve sıralaması değiştirilebilir.

### ⚙️ Backend (Node.js & Socket.io)
- **Gerçek Zamanlı İletişim:** Tüm ihbarlar, risk bölgeleri ve kullanıcı oturumları Socket.io üzerinden milisaniyeler içinde tüm cihazlara senkronize edilir.
- **Kalıcı Veri:** Kullanıcılar, menüler ve ihbarlar sunucuda tutulur. Render üzerinde 7/24 aktif çalışacak şekilde tasarlanmıştır.

### 💻 Admin Paneli (React & Vite)
- **Kontrol Paneli:** Sisteme kayıtlı kullanıcıları ve oluşturulan tüm acil durum ihbarlarını tek bir ekrandan yönetme imkanı.
- **Dinamik Menü Yönetimi:** Mobil uygulamanın alt menülerini kod yazmadan gizleyip açma ve sürükle-bırak mantığıyla sıralarını değiştirme.

---

## 🛠️ Kullanılan Teknolojiler

- **Mobil:** React Native, Expo, React Native WebView, Leaflet, Async Storage
- **Backend:** Node.js, Express, Socket.io
- **Admin Paneli:** React, Vite, Tailwind CSS (gerekli modüller), Socket.io-client
